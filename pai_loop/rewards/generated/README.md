# pai_loop/rewards/generated — LLM が生成した報酬

[scripts/loop.py](../../../scripts/loop.py) が ループ 1 周ごとに 1 ファイルを書き出す場所。手で編集しない。

## 命名とヘッダ

- ファイル名: `<exp>_L<i>.py`（`<exp>` の `i` 周目）
- 1 行目の docstring: `Generated by LLM for: <日本語の指示> (<exp名>).`（`loop.py` が付ける）
- 中身は [契約](../README.md)どおりの `PARAMS` / `compute` / `failed`（必要なら補助関数）

## 生成から学習までの流れ

1. `loop.py` が LLM に報酬を依頼し 返答から Python コードを取り出して このディレクトリに保存
2. `reward_check.load_and_check` で検証。失敗したらエラー文を LLM に返して同じファイル名で上書き（最大 `--gen-retries` 回）
3. 検証を通った `PARAMS` を `configs/<exp>_L<i>.yaml` の `reward.params` に書き出す
4. `scripts/train.py` がこのファイルを `runs/<exp>_L<i>/reward.py` にもコピー（再現用）
