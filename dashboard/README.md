# dashboard — 指示から学習・結果までを見せる画面

日本語の指示を入れると自動ループ（`scripts/loop.py`）が走り、今どの段階か・学習の進み・結果の動画と採点を1画面で見せる。標準ライブラリのみ。

```bash
python -m dashboard.server --root . --port 8765          # 実行も受け付ける
python -m dashboard.server --root . --port 8765 --no-run # 閲覧・再生のみ
```

127.0.0.1 にだけ待ち受ける。別のPCからは SSH トンネルで開く（`ssh -L 8765:127.0.0.1:8765 <host>`）。

| ファイル | 役割 |
|---|---|
| `state.py` | `logs/events/<exp>.jsonl`（`pai_loop/events.py` が `loop.py` から書く）と `logs/loops/<exp>.jsonl` から、実験の状態を組み立てる。イベントが無い古い実験は記録された所要時間から時系列を再構成し、`synthetic: true` を付ける。 |
| `server.py` | HTTP サーバー、実行キュー（GPUは1つなので順番に実行）、動画の Range 配信。実行の受付は、承認済みの成功条件がある芸だけ、同一オリジン、実験名・指示長の検証つき。 |
| `static/` | 画面。ライブ表示と、記録の再生（×1/×4/×16）を同じ描画で行う。 |

画面に絶対パス・アカウント名・バケット名は出さない。

## 画面の使い方

- 指示を入力して「学習を始める」を押すと、成功条件の草案が出ます。基準の数値を直したり、足したり外したりして、「確認した。承認して学習を始める」を押すと、学習が始まります。すでに承認した成功条件に当てはまる指示なら、それを使うかどうかを聞かれます。
- 学習中は、フローチャート（指示、報酬生成、検証、学習、録画、数値判定、AI採点、判定）の、いま動いている段階が光ります。各段階をクリックすると、その段階の説明、この周のデータ、実装のコードが右から開きます。
- 周の番号を押すと、その周の結果に切り替わります。終わったあとは、最も評価の高い周（★）が表示されます。緑の枠は「合格」だけで、オレンジは惜しい、赤は遠い結果です。
- 数値判定は「何項目中いくつ合格か」、AI 採点は 10 点満点で、8 点以上が合格です。両方合格で成功です。
- 動画の右上のボタンで、関節と軌跡（`J`）、座標の目盛り（`G`）、視点（`V`。骨格を 3D で見て、ドラッグで回す）を切り替えます。グラフは動画と同期していて、クリックでその場面に移れます。
- 結果が思わしくないとき（成功したあとでも）、「成功条件を見直して再学習」から、AI が出す見直し案を確認できます。新しい基準を、これまでの録画に当てはめた結果が表で出るので、学習し直さずに効果を確かめられます。承認すると、前の実験の報酬コードと指摘を引き継いで、再学習が始まります。
- 学習の途中で止めるときは、「強制終了」を押します（この画面から始めた実行だけ）。
- 「過去の実験を開く」で、記録した実験を見られます。「経過を再現」は、記録した経過を早送りで見直す機能で、学習をやり直すものではありません。
