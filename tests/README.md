# tests — ユニットテスト

GPUもtorchも不要な、標準ライブラリの `unittest` によるテスト。手元（Python 3.8）とVM（Python 3.12）の両方で動く。

```bash
python -m unittest discover -s tests          # リポジトリのルートから。-v で詳細
```

| ファイル | 内容 |
|---|---|
| `helpers.py` | 合成した1エピソード（クォータニオン、足の位置、円運動など）を作る補助関数 |
| `test_metrics.py` | `pai_loop/metrics.py`: 前向き軸と向き、±180°をまたぐヨーの巻き戻し、垂直に近いときのヨーの据え置き、円を描いて戻る動き（直線距離は小さく、最大距離は大きい）、足の左右差、従来のキーが残ること |
| `test_check_success.py` | `scripts/check_success.py` をサブプロセスで実行し、終了コード（合格0・不合格1・判定不能2）、結果ファイルの保存、未承認の拒否と検証用フラグ、入力が無いときの扱いを確認する |
| `test_success.py` | `pai_loop/success.py`: 成功条件の検証（未知の指標、`min_fraction` の要不要、ルールは1つだけ、非有限値など）、未承認の拒否、ハッシュ、お座りとその場旋回の合否、合格率の意味、指標が無いときの扱い、同梱の成功条件（`configs/tasks`）が常に検証を通ること |

- 実装を意図的に壊す変異（常に合格／ヨーの巻き戻し無効／最大距離を直線距離にすり替え／合格率の無視）で、テストが失敗することを確認済み。
- 学習・録画・LLM呼び出しを含むエンドツーエンドの確認は、このテストの対象外（VMで `scripts/loop.py` を短く回して確認する）。
