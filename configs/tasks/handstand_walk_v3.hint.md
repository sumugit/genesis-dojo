過去の試行（逆立ち歩行）を人が録画で見て分かったこと:
- 前足を地面に着けたまま滑らせて移動する、頭や肘（前足の膝）で体を支える、という抜け道が多かった。足先だけで支え、前足を左右交互に持ち上げて踏み出すこと。
- 「進んだ距離」だけを報酬にすると、足を持ち上げずに滑って進む方策が勝つ。踏み出しの動作そのものを報酬にすること。

設計の方針（参考）:
- 観測には、周期1.5Hz の sin/cos（時計）が入っている。報酬側でも、位相 phase = 2π・1.5・s.episode_time を使って「歩きの予定」を作れる。
  例: sin(phase) > 0 の間は前左の足が遊脚（持ち上げ、高さ0.08m前後）で前右が支持脚（接地、高さ0.05m以下）、sin(phase) < 0 の間は逆。
  足の高さが予定に合うほど報酬、合わなければ小さい罰。
- 遊脚の高さは 0.06〜0.12m 程度の持ち上げを目標にする。高すぎると倒れる。
- 支持脚（接地している前足）は少なくとも1本は常に地面に着ける。両方が同時に浮かないようにする。
- 進行は、水平方向の移動速度（開始位置からの距離が増える速さ。向きは問わない）に、緩い報酬をかける。速すぎる必要はない（0.3〜0.8 m/s 程度）。
- 逆立ちの姿勢の維持（頭が下、後ろ足が上）は、これまでどおり主要な項にする。head_pos の高さ 0.2m 以上、前足の膝（knee_pos の前2本）の高さ 0.12m 以上を保つ項（下回ったら大きな罰）を入れる。
- 打ち切り（failed）は、転倒や胴体の接地など明らかな失敗に限る。厳しすぎると学習が進まない。
