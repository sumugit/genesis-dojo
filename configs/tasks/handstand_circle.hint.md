過去の試行（逆立ちで円を描いて歩く）を人が録画で見て分かったこと:
- 最初の試行では、毎回すぐ倒れた。円を描く動きの前に、逆立ち歩行そのものが安定していなかった。
- 逆立ち歩行（直進）は、観測の時計（周期1.5Hz の sin/cos）と、前足の交互の踏み出しを報酬にすることで安定した（下の歩行の方針を参照）。
- 前足を地面に着けたまま滑らせる、頭や肘（前足の膝）で支える、という抜け道が多かった。足先だけで支え、前足を左右交互に持ち上げること。

歩行の方針（直進で成功した設計。まずこれを土台にする）:
- 位相 phase = 2π・1.5・s.episode_time。sin(phase) > 0 の間は前左が遊脚（高さ0.08m前後）・前右が支持脚（0.05m以下）、sin(phase) < 0 の間は逆。足の高さが予定に合うほど報酬。
- 遊脚の高さは 0.06〜0.12m。支持脚は少なくとも1本は常に接地。
- 逆立ちの姿勢（頭が下、後ろ足が上）が主要な項。head_pos の高さ 0.2m 以上、前足の膝（knee_pos の前2本）の高さ 0.12m 以上を保つ項を入れる。
- 打ち切り（failed）は、転倒や胴体の接地など明らかな失敗に限る。厳しすぎると学習が進まない。

円を描く方針:
- 向きの定義が難しいので、胴体の向きではなく、水平方向の移動速度ベクトルの向きで考える。
- 目標: 速さ 0.3〜0.5 m/s で、進む向きが一定の角速度（0.3〜0.5 rad/s 程度。向きは左右どちらでも固定）で回り続ける。半径はおよそ 速さ÷角速度（約1m）。
- 例: 目標の向き θ(t) = ω・s.episode_time を作り、水平速度が (cos θ, sin θ)・v_target に近いほど報酬。直進が優先されないようにする。
- 円を描くのは歩行が安定してから。回る項は、歩行・姿勢の項より弱くして、転ばないことを優先する。
